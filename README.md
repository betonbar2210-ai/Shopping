# SkyproStore

Учебный интернет-магазин на Django с онлайн-блогом, авторизацией пользователей и управлением товарами.

## Возможности

- Регистрация, вход по электронной почте и редактирование профиля
- Каталог товаров с категориями, просмотром и редактированием
- Блог со статьями
- Защита разделов управления от анонимных пользователей
- Приветственное письмо после регистрации

## Технологии

- Python 3.14
- Django 6.1
- PostgreSQL
- Bootstrap 5

## Установка и запуск

1. Клонируйте репозиторий.
2. Установите зависимости:

   ```
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` в корне проекта по образцу `.env.example` и заполните значения:

   ```
   DATABASE_NAME=...
   DATABASE_USER=...
   DATABASE_PASSWORD=...
   DATABASE_HOST=...
   DATABASE_PORT=5432
   SECRET_KEY=...
   DEBUG=True
   ```

4. Примените миграции:

   ```
   python manage.py migrate
   ```

5. Запустите сервер:

   ```
   python manage.py runserver
   ```

6. Откройте http://127.0.0.1:8000/

## Тесты

Запуск тестов:

python manage.py test
