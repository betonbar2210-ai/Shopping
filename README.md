# SkyproStore

Веб-приложение магазина на Django с каталогом товаров и страницей контактов.

## Описание проекта

Проект реализует:
- Главную страницу магазина
- Страницу контактов с формой обратной связи
- Базовую навигацию и стилизацию через Bootstrap 5

## Технологии

- Python 3.14.4
- Django 6.0.7
- HTML/CSS
- Bootstrap 5

## Установка и запуск

1. Клонируйте репозиторий.
2. Создайте и активируйте виртуальное окружение
3. Запустите сервер: python manage.py runserver
4. Откройте в браузере: http://127.0.0.1:8000/
